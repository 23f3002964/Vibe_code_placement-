# University Placement Portal

A Flask-based web application for managing university placement activities, connecting students with companies for internships and job opportunities.

## Features

- Student dashboard for job applications and profile management
- Company portal for posting jobs and reviewing applications
- Admin dashboard for system management
- Job listings with search and filtering capabilities
- Responsive design for desktop and mobile devices

## Installation

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`

## Usage

- Visit `http://localhost:5000` to access the placement portal
- Navigate using the top menu to access different sections

## Structure

- `app.py` - Main Flask application
- `templates/` - HTML templates for the application
- `static/` - CSS, JavaScript, and image files (to be added)
- `requirements.txt` - Python dependencies

## Dependencies

- Flask
- Jinja2
- Werkzeug
